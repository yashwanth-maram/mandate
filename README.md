# Mandate

Intent-aware verification for autonomous payments.

**Razorpay AI Buildathon 2026 — Track 02 (AI Risk Manager)**

Loss class: agent-performance failure. A payment can be authorised, within
mandate, and correctly fulfilled by the merchant, and the buyer can still be
harmed — because the agent asked for the wrong thing. Authorisation checks,
fraud scoring, and UPI dispute grounds are all blind to this.

Work in progress.
